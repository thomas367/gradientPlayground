# Gradient Playground

An interactive CSS gradient playground to create, customize, preview, and export linear, radial, and conic gradients.

## Features

- Linear gradients
- Radial gradients
- Conic gradients
- Live gradient preview
- Customizable colors and gradient settings
- CSS code generation

## Tech Stack

- React
- TypeScript
- Vite
- styled-components
- Jest
